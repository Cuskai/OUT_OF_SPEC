# Historical Punchy Integration Note

Earlier OUT OF SPEC RPG prototypes bundled Punchy 2.8f under permission reported by the project owner from its author, Dev Punchy Man. This note is retained only as a project-history record.

Stage 5.3.20 no longer ships the Punchy JAR or its compiled classes/resources, does not register the `punchy` mod ID, and does not depend on or target Punchy's renderer. The current build is standalone; the prior authorization is not used to redistribute Punchy in this release.
